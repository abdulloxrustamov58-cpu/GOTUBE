YOUTUBE PRO FULL — Windows 10

1. ZIP faylni Extract All orqali chiqarib oling.
2. YOUTUBE_PRO_FULL papkasini VS Code bilan oching.
3. Terminal > New Terminal ni bosing.
4. npm install
5. npm start
6. Brauzerda http://localhost:3000 ni oching.

Ro‘yxatdan o‘tish uchun Kirish tugmasini bosing, so‘ng Ro‘yxatdan o‘tish ni tanlang.
Video yuklash uchun akkauntga kirib, + Yuklash tugmasini bosing.

Mavjud: akkaunt, video yuklash/ko‘rish, qidiruv, kategoriyalar, like, izoh, kanal, obuna,
Creator Studio statistikasi va ko‘rish tarixi.

Muhim: bu kompyuterda lokal ishlaydigan MVP. Ma’lumotlar data/db.json da, videolar uploads da
saqlanadi. Ommaviy saytga chiqarishdan oldin haqiqiy ma’lumotlar bazasi, bulutli video saqlash,
HTTPS, maxfiylik va xavfsizlik, moderatsiya va zaxira nusxalar sozlanishi kerak.
